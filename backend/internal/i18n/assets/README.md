# 后端国际化目录

本目录存放后端返回给客户端的结构化错误消息，以及代码生成器使用的固定文案。代码生成器文案使用 `system.code.gen.*` 前缀，与错误消息共用同一套按语言拆分的 JSON 目录。`embed.go` 只负责把本项目语言文件提供给宿主，宿主通过 `kratos-core/resource/i18n` 注入资源，通用目录加载和错误本地化由 Core 内部完成。

| 文件 | 用途 | 使用位置 |
| --- | --- | --- |
| `zh-CN.json` | 中文基准目录；错误消息和 `system.code.gen.*` 文案必须先在这里定义。 | 校验源文、消息键、占位符并作为默认回退。 |
| `zh-TW.json` | 繁体中文后端目录。 | 按 `Accept-Language` 请求头选择。 |
| `en-US.json` | 英文后端目录，与中文保持完全相同的消息键和占位符。 | 按 `Accept-Language` 请求头选择。 |
| `ja-JP.json` | 日语后端目录，与中文保持完全相同的消息键和占位符。 | 按 `Accept-Language` 请求头选择。 |

这些 JSON 文件必须保持标准 JSON，不能写 `//` 或 `/* ... */` 注释。修改后从仓库根目录执行 `make i18n-check` 检查，再执行 `make i18n-sync` 更新注册产物；检查所有语言的键集合和占位符。

新增语言的完整文件清单见[国际化语言扩展指南](../../../../docs/国际化语言扩展指南.md)。
