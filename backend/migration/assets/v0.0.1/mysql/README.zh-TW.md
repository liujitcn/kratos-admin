# 預設系統資料

初始化預設租戶、部門、崗位、字典、設定、選單、語言、角色，以及 `super`、`admin` 開發帳號。語言預設資料和語言管理選單已合併至 `default_data.up.sql`；語言表由資料層自動遷移建立，統一翻譯表會在寫入語言 SQL 前冪等建立。管理端維護語言代碼、名稱、啟用狀態、主要語言標記和排序，動態翻譯介面的語言選項透過語言管理 API 讀取。

同時提供管理端 System 頁面、AI、程式碼生成、API 文件、專案文件、運維監控、執行日誌及應用端公共能力所需的選單與受保護服務方法權限。開發工具選單依「運維監控 → 執行日誌 → 程式碼生成」排序，執行日誌預設僅超級管理員具有存取權限，並關聯即時主控台、SSE 訂閱、歷史日誌查詢和原始檔案下載介面。行動端根選單固定為 `999`，首頁為 `99901`，我的頁面為 `99909`，其餘第二層編號保留給業務模組使用；頁面設定統一儲存在 `base_menu.meta.app`，每個頁面選單只關聯實際呼叫的受保護 API。專案文件在建置時收集並嵌入 Backend 二進位檔，專案識別碼與對應 OpenAPI/Swagger 文件 key 保持一致。OAuth 自動註冊與租戶編號顯示使用布林設定；OpenAPI 介面中繼資料和 Casbin 原則會在服務啟動時同步。

翻譯資料按語言拆分為 `i18n.{locale}.up.sql`，目前包含 `zh-TW`、`en-US` 和 `ja-JP`。每個檔案只包含對應語言的 `base_i18n` 資料，並透過 `target_type` 區分字典名稱、選單標題、字典項標籤、系統設定名稱和值，以及排程任務名稱。每筆翻譯使用獨立的 `INSERT IGNORE`，檔名排序可確保主要資料先於翻譯資料執行。

`base_job` 在不同業務模組間使用固定編號區段：kratos-admin 使用 `1000-1999`，內建資源翻譯任務編號為 `1000`；後續模組從 `2000` 開始，每個模組保留 1,000 個編號。
