# 默认系统数据

消息分类与消息业务表由数据层自动迁移创建，SQL 脚本只初始化默认分类、任务、菜单、按钮和权限，不包含建表语句。

初始化默认租户、部门、岗位、字典、配置、菜单、语言、角色和 `super`、`admin` 开发账号。语言默认数据和语言管理菜单已合并到 `default_data.up.sql`，语言表由数据层自动迁移创建；统一翻译表在写入语言 SQL 前幂等创建。管理端维护语言代码、名称、启用状态、主语言标记和排序，动态翻译界面的语言选项通过语言管理接口读取。

同时提供管理端 System 页面、AI、代码生成、API 文档、项目文档、运维监控、运行日志及应用端公共能力所需的菜单和服务方法权限。开发工具菜单按“运维监控 → 运行日志 → 代码生成”排序，运行日志仅超级管理员默认拥有访问权限，并关联实时控制台、SSE 订阅、历史日志查询和原文件下载接口。固定移动端根目录为 `999`，二级首页使用 `99901`、二级我的使用 `99909`，其余二级编号预留业务使用；页面配置统一保存在 `base_menu.meta.app`，每个页面菜单分别关联自身实际调用的受保护 API，根目录只关联移动菜单查询。项目文档在构建期收集并嵌入 Backend 二进制，项目标识与对应 OpenAPI/Swagger 文档 key 保持一致；OAuth 自动注册与租户编号显示使用布尔配置；OpenAPI 接口元数据和 Casbin 策略在服务启动时按当前文档与菜单关系同步。

翻译数据按语言拆分为 `i18n.{locale}.up.sql`，当前包含 `zh-TW`、`en-US` 和 `ja-JP`。每个文件只包含对应语言的 `base_i18n` 数据，并通过 `target_type` 区分字典名称、菜单标题、字典项标签、系统配置名称和值以及定时任务名称。每条翻译记录使用一条 `INSERT IGNORE`，不使用批量 `INSERT ... SELECT` 或 `UNION ALL`；文件名排序确保主数据先于翻译数据执行。

`base_job` 使用跨业务固定编号段：kratos-admin 占用 `1000-1999`，内置资源翻译任务编号为 `1000`、消息投递恢复任务编号为 `1001`、审计日志归档任务编号为 `1002`、数据库备份任务编号为 `1003`；后续业务从 `2000` 开始，每个业务预留 1000 个编号。审计归档配置 `AUDIT_ARCHIVE_INTEGRITY_KEY` 后启用，默认计划每天 03:30 执行；数据库备份任务默认关闭，启用时必须显式设置 `BACKUP_ENABLED=true` 和 `MYSQLDUMP_DATABASE`。

登录策略菜单由 `security_login_policy.up.sql` 初始化，仅平台超级管理员可见；普通租户角色不授予该菜单和接口权限。

MFA 与开放授权客户端的初始化数据直接写入 `default_data.up.sql`，包含策略、认证方式、管理菜单、服务方法权限和管理员角色菜单；MFA 表与 OAuth 客户端表由数据层自动迁移创建。
