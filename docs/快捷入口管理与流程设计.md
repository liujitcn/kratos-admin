# AI 快捷入口管理与流程设计

## 管理入口

管理端菜单为「AI 助手 → 快捷入口」。列表提供搜索、分页、新增、查看、编辑、批量删除和启停。弹窗分为基本信息和流程设计两步。

| 步骤 | 内容 |
| --- | --- |
| 基本信息 | 填写名称、标识、来源、终端、提问内容和排序。API 来源显示工具选择器。新增时可设初始状态，已有入口从列表启停。 |
| 流程设计 | 选择仅发送提示词或在管理端画布上配置节点、连线和参数。应用端支持发送提示词。校验通过后可直接保存。 |

## 存储与权限

入口与当前生效的流程一起保存，使用一个 `ai_shortcut` 记录。工具依赖由主工具和流程节点派生。API 选择器保存 `tool_name`，例如 `base_v1_account_service_get_current_password_policy`。

| 字段 | 类型与用途 |
| --- | --- |
| `id`、`tenant_id` | bigint，入口主键和认证租户 |
| `shortcut_key`、`title` | varchar(100)、varchar(200)，入口标识和展示名称 |
| `source_type`、`terminal` | smallint，入口来源与适用终端 |
| `tool_name` | varchar(150)，API 来源的主工具。自定义来源留空 |
| `prompt`、`group_name`、`sort` | text、varchar(100)、int，提问内容、历史分组和排序 |
| `status` | smallint，沿用系统启停状态 |
| `node_config` | text，管理端流程图 JSON。仅提示词时为空 |
| `revision` | bigint，每次更新或启停递增 |
| `created_by`、`updated_by`、`created_at`、`updated_at`、`deleted_at` | 审计时间、操作人和软删除 |

租户、终端和入口标识构成有效记录的唯一约束。列表和写入均使用当前认证租户。初始化菜单向平台管理员角色分配管理权限，按钮分别控制创建、更新、删除与启停。详情由页面权限提供。

## 对话行为

启用的入口通过现有 `ListAiShortcut` 展示。依赖工具须在请求终端登记、处于启用状态且已经授权。带流程的入口执行时按当前会话重新解析工具池，并校验租户和当前配置修订号。只有会话最新一轮助手回复可以继续，配置更新后旧动作失效。重试和重新生成使用该轮保存的流程动作，再次校验配置和工具权限。

| 节点 | 配置 |
| --- | --- |
| START 和 END | 开始与结束，保留固定节点编号。 |
| PROMPT | 可用 `{"text":"…"}` 设置本步骤的模型提示词，留空使用入口提问内容。 |
| TOOL | 选择已授权的只读 API，参数为该接口接受的 JSON 对象。 |
| BRANCH | 按顺序匹配最近一次工具或模型 JSON 输出中的字段，例如 `total == 1`。每个分支必须有一条 `default` 连线。 |
| CONFIRM | 可用 `{"text":"…"}` 自定义按钮文案。用户点击后从下一节点继续，并沿用服务端保存的上一步结果。 |

流程图限制为 24 个节点和 48 条连线。保存时校验节点编号、步骤标识、参数与拓扑。确认节点用于继续当前流程，业务工具仍使用现有授权规则。

旧消息如果没有保存原始动作或确认前的结果，需要从快捷入口重新发起。

## 上线

启用模型自动迁移时创建 `ai_shortcut` 表。MySQL 和 PostgreSQL 的 `v0.0.1` 初始化资源包含菜单 `90150000` 及按钮 `90150001` 至 `90150004`。已记录该版本的环境需要同步这组菜单和角色授权。
