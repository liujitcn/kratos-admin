# 当前功能总览

本文只记录本仓库已经落地并由当前代码维护的功能。接口、字段、菜单和命令发生变化时，以代码和生成产物为准，再同步更新本文。

## 后端能力

- 账号登录、验证码、OAuth、TOTP/WebAuthn 多因素认证、恢复码、JWT 刷新和会话撤销。
- 多租户、用户、角色、部门、岗位、菜单、字典、配置、API、Casbin 权限和项目授权。
- 登录来源策略、密码复杂度、密码有效期、多设备登录、在线会话、登录审计和六类业务审计日志。
- 文件上传、对象存储、公开文件访问、敏感字段传输加密、落库信封加密和按权限查看密钥。
- 定时任务、任务日志、数据库迁移记录、表归档、数据库备份与恢复、运行日志和 SSE 订阅。
- 站内信分类、定向或全员发布、收件箱、未读数、已读、归档、撤回、过期清理和失败恢复。
- AI 会话、附件、流式响应、工具调用、智能问数、供应商与模型管理、知识库文档处理和检索增强对话。
- 开放授权客户端、Bearer Token、API 操作白名单、来源限制、请求加解密和限流策略。
- 由 Proto 驱动的 HTTP、gRPC、OpenAPI、TypeScript RPC、Agent Tool、MCP Tool 和代码生成能力。

## 三个前端入口

### 管理端

管理端提供登录和 MFA、工作台、用户与组织、租户与项目、菜单权限、系统配置、国际化、任务、日志、备份、文件、OAuth/消息 Provider、AI 和代码生成页面。公共 core 提供动态路由、布局、主题、表格、表单、上传、Markdown 预览和敏感字段查看组件；System 与 RAG 是当前仓库内置业务模块。

### uni-app

uni-app 支持 H5 和微信小程序，提供首页、登录、协议、WebView、个人中心、资料、设置、消息中心和 AI 助手。页面由模块清单和稳定 `viewKey` 装配，动态菜单由后端返回并经过访问模式校验，底部导航和顶部导航由 core 统一渲染。

### Taro

Taro 支持 H5 和微信小程序，提供与 uni-app 对齐的应用能力。core 负责认证、请求、路由、动态页面装配和导航，UI 包负责 NutUI 主题适配，System 模块负责个人中心、设置、资料、消息中心和 AI 助手。

## 数据与运行

- MySQL 保存业务数据、权限、迁移记录和站内信事实；AI 知识库可按配置使用独立数据源，未配置时回落默认数据源。
- Redis 用于缓存、分布式锁、队列和消息投递；未配置时单实例回退进程内实现，多实例必须使用共享 Redis。
- 本地对象存储、S3 兼容对象存储和文件安全扫描均通过配置启用。
- 默认配置位于 `backend/configs`，完整字段模板位于 `backend/configs/full`；敏感配置使用 `ENC[...]`，运行密钥通过密钥服务读取。
- 初始化数据统一维护在 `backend/migration/assets/v0.0.1/mysql`，包括表外的菜单、按钮、API 权限、默认账号和多语言数据。

## 主要入口

| 入口 | 作用 |
| --- | --- |
| `make -C backend run-minimal` | 使用最小配置启动后端 |
| `make -C frontend run` | 启动管理端、uni-app 和 Taro 开发环境 |
| `make gen` | 生成协议、数据库访问、Wire、RPC 和语言资源 |
| `make check` | 执行后端、三个前端和国际化检查 |
| `make build` | 构建后端和三个 H5 宿主 |
| `make i18n` | 同步并生成多语言资源和 OpenAPI 文档 |
| `make docker-build` | 构建多架构 Docker 镜像 |

## 明确不包含

本仓库功能边界不包含商城、订单、支付、推荐等业务模块。
