# 前端组件清单

本文只记录当前代码中存在、可直接使用的组件及其边界。管理端组件实现位于 `frontend/admin/packages/core/src/components`；应用端目前没有公共组件目录，只有 AI 页面私有组件。

## 管理端选型

| 场景 | 组件 | 说明 |
| --- | --- | --- |
| 分页列表、搜索、列设置、批量操作 | `ProTable` | 使用 `columns`、`headerActions` 和 `requestApi` 配置列表。 |
| 新增或编辑弹窗 | `FormDialog` | 组合 `ProDialog` 与 `ProForm`，页面负责校验、提交和刷新。 |
| 详情、预览或非表单弹窗 | `ProDialog` | 内容通过默认插槽或具名插槽组织。 |
| 配置式表单 | `ProForm` | 字段由 `ProFormField[]` 描述，支持输入、选择、字典、上传、富文本等现有控件。 |
| 字典选择与展示 | `Dict`、`DictLabel` | 由 core 启动流程注册为全局组件。 |
| 图片上传 | `UploadImg` | core 对外公开的上传组件；多图和文件上传目前只供 core 内部使用。 |
| 树形筛选 | `TreeFilter` | 支持静态数据或请求加载、单选和多选。 |
| 图标选择 | `SelectIcon` | 选择 Element Plus 图标名称。 |
| 富文本 | `WangEditor` | 封装 wangEditor，并复用文件上传服务。 |
| 密码强度 | `PasswordStrength` | 登录、用户和个人中心密码表单使用。 |

`CronExpression`、`ECharts`、`Grid`、`ImportExcel`、`SelectFilter`、`SwitchDark` 等组件确实存在，但尚未通过 npm `exports` 开放，只应在 core 内部使用。是否可跨包引用以 `frontend/admin/packages/core/package.json#exports` 为准，不能把源码目录当成公共接口。

## 公共导入入口

业务模块使用 core 包公开入口，不引用 `packages/core/src`：

```ts
import ProTable from "@liujitcn/kratos-admin-core/components/ProTable";
import FormDialog from "@liujitcn/kratos-admin-core/components/Dialog/FormDialog.vue";
import type {
  ColumnProps,
  HeaderActionProps,
  ProTableInstance
} from "@liujitcn/kratos-admin-core/components/ProTable/interface";
import type {
  ProFormField,
  ProFormInstance
} from "@liujitcn/kratos-admin-core/components/ProForm/interface";
```

| 组件 | npm 入口 |
| --- | --- |
| `FormDialog` | `@liujitcn/kratos-admin-core/components/Dialog/FormDialog.vue` |
| `ProDialog` | `@liujitcn/kratos-admin-core/components/Dialog/ProDialog.vue` |
| `DictLabel` | `@liujitcn/kratos-admin-core/components/Dict/DictLabel.vue` |
| `PasswordStrength` | `@liujitcn/kratos-admin-core/components/PasswordStrength/index.vue` |

## 列表与表单

### ProTable

`ProTable` 的列类型定义在 `packages/core/src/components/ProTable/interface/index.ts`。常用配置包括：

- `columns`：列、搜索项、字典、状态和行操作。
- `requestApi`：分页请求，返回 `{ data: { list, total } }`。
- `headerActions`：新增、批量删除等表头操作。
- `cellType`：现有 `image`、`status`、`actions`、`money` 单元格。
- `dictCode`：使用系统字典展示或搜索。

页面请求使用 core 的表格工具转换分页参数：

```ts
import { buildPageRequest } from "@liujitcn/kratos-admin-core/table";

async function requestTable(params: Record<string, unknown>) {
  const response = await service.PageResource(buildPageRequest(params));
  return {
    data: {
      list: response.resources ?? [],
      total: response.total
    }
  };
}
```

表格实例提供重新请求、搜索、重置、清空选择以及读取当前选择和分页状态等能力，具体类型以 `ProTableInstance` 为准。

### ProForm 与 FormDialog

`ProFormField` 当前支持输入框、数字、分段选择、复选框、开关、下拉、单选、多选、字典、树选择、日期、Cron、穿梭框、图片和文件上传、富文本、动态列表、键值列表及自定义插槽。

典型弹窗只需要公开组件和字段类型：

```vue
<FormDialog
  ref="dialogRef"
  v-model="dialogVisible"
  :model="formModel"
  :fields="formFields"
  :rules="rules"
  @confirm="handleSubmit"
  @closed="resetForm"
/>
```

`FormDialog` 只负责交互与校验入口，不自动调用业务接口。页面在确认事件中执行 `validate()`、提交 service、关闭弹窗并刷新表格，关闭后显式重置模型和校验状态。

## 内部组件

以下组件是现有实现，但未列入公共 npm 入口：

| 目录 | 能力 |
| --- | --- |
| `components/CronExpression` | 六段式 Cron 编辑。 |
| `components/ECharts` | Bar、Line、Pie 等图表容器。 |
| `components/Grid`、`SearchForm` | ProTable 搜索区域的响应式布局。 |
| `components/ImportExcel` | Excel 文件导入弹窗。 |
| `components/Loading` | 页面和全屏加载状态。 |
| `components/SelectFilter` | 多组筛选条件。 |
| `components/SwitchDark` | 明暗主题切换。 |
| `components/Upload` | 单图、多图、单文件、多文件上传。 |

业务模块需要其中某项能力时，先确认是否已有公开入口。确有跨模块复用需求，再在 core 的 `package.json#exports` 增加明确的单组件入口，并同步构建与类型检查；不要增加 `components/*` 通配导出。

## 布局与页面组件

四种管理端布局位于 `frontend/admin/packages/core/src/layouts`：`LayoutVertical`、`LayoutClassic`、`LayoutTransverse`、`LayoutColumns`。它们由 core 路由和全局设置选择，不作为业务页面组件使用。

System 模块的页面私有组件位于 `frontend/admin/packages/modules/system/src/views/**/components`，例如用户页部门树、个人中心表单和代码生成预览组件。`src/components/Ai.vue` 是 System 注册到顶部工具栏的 AI 入口。这些组件目前都没有 npm 公共导出。

## 应用端组件

应用端当前只有 `frontend/app/src/pagesMember/ai/components` 下的三个页面私有组件：

| 组件 | 用途 |
| --- | --- |
| `Composer.vue` | 消息输入、附件和发送操作。 |
| `SessionDrawer.vue` | 会话列表与切换。 |
| `WelcomePanel.vue` | AI 页面欢迎区和快捷入口。 |

它们只服务 `pagesMember/ai/index.vue`，不属于 `@liujitcn/kratos-app` 的公共组件接口。至少两个页面出现无业务语义的真实复用后，再考虑提升到公共组件目录。

## 维护依据

- 管理端公共导出：`frontend/admin/packages/core/package.json#exports`
- 管理端组件源码：`frontend/admin/packages/core/src/components`
- System 页面与私有组件：`frontend/admin/packages/modules/system/src`
- 应用端页面私有组件：`frontend/app/src/pagesMember/ai/components`

组件属性和实例方法以同目录 Vue/TypeScript 类型定义为准；本文不复制完整 props，避免实现调整后文档继续保留失效能力。
