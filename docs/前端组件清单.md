# 前端组件清单与使用说明

## 文档范围

本文以当前源码为准，整理两个前端入口中的 Vue 组件：

- `frontend/admin/src/components`：管理后台可复用组件，是本文的主要内容。
- `frontend/admin/src/layouts`、`frontend/admin/src/views/**/components`：管理后台布局和业务私有组件，仅在需要扩展对应页面时参考。
- `frontend/app/src/pagesMember/ai/components`：应用端 AI 页面私有组件，目前没有提升到 `frontend/app/src/components` 的通用组件。

Element Plus 组件通过 Vite 自动导入，Element Plus 图标在启动时全局注册；`Dict`、`DictLabel`、`SvgIcon` 也在 `frontend/admin/src/bootstrap.ts` 中全局注册。其余管理后台自定义公共组件通常需要显式导入。

```ts
import ProTable from "@/components/ProTable/index.vue";
import FormDialog from "@/components/Dialog/FormDialog.vue";
import type { ColumnProps } from "@/components/ProTable/interface";
```

路径中的 `@` 指向 `frontend/admin/src`，应用端使用 `@` 指向 `frontend/app/src`。

## 选型速查

| 场景 | 首选组件 | 说明 |
| --- | --- | --- |
| 分页列表、查询、列设置、批量操作 | `ProTable` | 通过 `columns`、`headerActions` 和 `requestApi` 配置，默认带搜索、分页和工具栏。 |
| 新增/编辑表单弹窗 | `FormDialog` | `ProDialog + ProForm` 的组合，统一处理校验、确定、取消和关闭。 |
| 非表单弹窗、详情或流程面板 | `ProDialog` | 保留弹窗生命周期，内容由插槽自行组织。 |
| 独立表单或复杂配置表单 | `ProForm` | 使用字段配置驱动控件，复杂内容通过 `slot` 字段和具名插槽扩展。 |
| 字典下拉、单选、多选 | `Dict` | 从字典 store 加载选项，统一处理字符串/数字值转换。 |
| 字典值展示 | `DictLabel` | 将编码转换为标签，可根据字典项的 `tag_type` 渲染标签颜色。 |
| 图片/文件上传 | `UploadImg`、`UploadImgs`、`UploadFile`、`UploadFiles` | 默认使用 `defFileService.UploadFile`，也可注入业务上传函数。 |
| 富文本 | `WangEditor` | 支持图片、视频自定义上传和 Element Plus 表单校验联动。 |
| 树形筛选 | `TreeFilter` | 支持单选、多选、关键字过滤、全部节点和懒加载。 |
| 定时任务表达式 | `CronExpression` | 提供常用表达式和秒/分/时/日/月/年分段编辑。 |
| 图表 | `ECharts` | 当前注册 Bar、Line、Pie 及常用组件，自动响应窗口和布局变化。 |

## 管理后台公共组件

### `ProTable`：配置式列表

文件：`frontend/admin/src/components/ProTable/index.vue` 及 `interface/index.ts`。

#### 主要属性

| 属性 | 类型 | 默认值 | 用途 |
| --- | --- | --- | --- |
| `columns` | `ColumnProps[]` | `[]` | 列、搜索项、字典、状态列和行操作配置。 |
| `requestApi` | `(params) => Promise<any>` | - | 服务端分页请求。返回值应包含 `{ data: { list, total } }`。 |
| `requestAuto` | `boolean` | `true` | 是否在挂载时自动请求。 |
| `data` | `any[]` | - | 静态数据；传入后不使用 `requestApi` 的列表结果。 |
| `pagination` | `boolean` | `true` | 是否显示分页。静态数据也会按分页参数切片。 |
| `initParam` | `any` | `{}` | 首次请求和参数变化时附加的业务参数。 |
| `headerActions` | `HeaderActionProps[]` | `[]` | 顶部按钮，支持 `hidden`、`disabled`、图标和选中行上下文。 |
| `toolButton` | `boolean | ("refresh" \| "setting" \| "search")[]` | `true` | 刷新、列设置、搜索按钮；传数组可以精确控制。 |
| `rowKey` | `string` | `"id"` | 行唯一键，也用于多选恢复。 |
| `restoreSelectedRowKeys` | `(string \| number)[]` | `[]` | 请求后恢复已勾选行。 |
| `border` | `boolean` | `true` | 是否显示纵向边框。 |
| `searchCol` | `number \| Record<BreakPoint, number>` | `{ xs: 1, sm: 2, md: 2, lg: 3, xl: 4 }` | 搜索表单栅格列数。 |

`ProTable` 会透传其他属性到 Element Plus `el-table`，例如 `tree-props`、`lazy`、`height`、`stripe` 和 `default-sort`。

#### 列配置重点

`ColumnProps` 除了 Element Plus 列属性，还支持：

- `type`：`selection`、`radio`、`index`、`expand`、`sort`。
- `search`：声明搜索控件，支持 `input`、`input-number`、`select`、`select-v2`、`tree-select`、`cascader`、`date-picker`、`time-picker`、`time-select`、`switch`、`slider`。
- `enum`、`dictCode`、`dictValueType`：为搜索选项或单元格格式化提供枚举/字典。
- `cellType`：`image`、`status`、`actions`、`money`，避免在每个页面重复写模板。
- `render`、`headerRender`：确实需要业务定制时使用 TSX 渲染函数。
- `actions`：行操作数组，每项包含 `label`、`onClick`，可选 `icon`、`type`、`link`、`hidden`、`disabled` 和 `params`。
- `isShow`、`isSetting`：分别控制当前列是否显示及是否出现在列设置中。

状态列示例：

```ts
const columns: ColumnProps[] = [
  {
    prop: "status",
    label: "状态",
    cellType: "status",
    statusProps: {
      activeValue: Status.ENABLE,
      inactiveValue: Status.DISABLE,
      activeText: "启用",
      inactiveText: "禁用",
      beforeChange: scope => handleBeforeSetStatus(scope.row)
    }
  }
];
```

#### 插槽和事件

- `tableHeader`：完全接管顶部左侧区域，作用域包含 `selectedList`、`selectedListIds`、`isSelected`。
- `toolButton`：完全接管顶部右侧工具栏。
- `default`、`expand`、列名插槽：用于复杂单元格或展开行；作用域与 Element Plus 表格一致。
- `append`、`empty`、`pagination`：分别扩展表尾、空态和分页。
- `search`、`reset`、`refresh`、`dragSort`：搜索、重置、刷新和拖拽排序通知。

#### 实例方法

```ts
const tableRef = ref<ProTableInstance>();

tableRef.value?.getTableList();       // 重新请求
tableRef.value?.search();             // 使用当前搜索参数请求
tableRef.value?.reset();              // 清空搜索并请求
tableRef.value?.clearSelection();     // 清空勾选
tableRef.value?.getTotal();           // 获取当前总数
tableRef.value?.refreshEnums();       // 重新加载 enum 数据
tableRef.value?.selectedList;         // 当前选中行
tableRef.value?.selectedListIds;      // 当前选中行 ID
tableRef.value?.searchParam;          // 当前搜索参数
tableRef.value?.pageable;             // 分页状态
```

典型页面骨架：

```vue
<ProTable
  ref="tableRef"
  row-key="id"
  :columns="columns"
  :header-actions="headerActions"
  :request-api="requestTable"
  :init-param="initParam"
/>
```

请求函数建议使用 `buildPageRequest(params)` 转换分页参数，并返回：

```ts
async function requestTable(params: Record<string, any>) {
  const response = await service.PageResource(buildPageRequest(params));
  return { data: { list: response.resources ?? [], total: response.total } };
}
```

### `ProForm`：字段配置驱动的表单

文件：`frontend/admin/src/components/ProForm/index.vue`、`interface/index.ts`。

属性为 `model`、`fields`、`rules`、`labelWidth`、`gutter`、`colSpan`。`fields` 使用 `ProFormField`：

| 字段 | 说明 |
| --- | --- |
| `prop` | 绑定路径，支持 `user.profile.name` 形式的点路径。 |
| `label` | 表单项标题。 |
| `component` | 见下方控件类型表。 |
| `props` | 透传给控件的参数，可按 `model` 动态返回。 |
| `itemProps` | 透传给 `el-form-item` 的参数，可按 `model` 动态返回。 |
| `options` | `select`、`radio-group`、`checkbox-group`、`tree-select`、`transfer` 的选项，可动态返回。 |
| `rules` | 字段级校验规则，优先于组件级 `rules`。 |
| `visible` | 返回 `false` 时隐藏字段。 |
| `colSpan`、`rowBreakBefore` | 控制栅格宽度和换行。 |
| `slotName` | `slot` 类型或控件内部自定义内容的插槽名。 |
| `labelTooltip` | 在标题旁显示帮助提示。 |

支持的 `component` 类型：

| 类型 | 实际控件 | 值形态/备注 |
| --- | --- | --- |
| `input`、`password`、`textarea` | `el-input` | 文本会使用 `trim` 双向绑定。 |
| `input-number` | `el-input-number` | 数字。 |
| `segmented` | `el-segmented` | 配合 `options`。 |
| `checkbox`、`switch` | `el-checkbox`、`el-switch` | 布尔值。 |
| `select`、`radio-group`、`checkbox-group` | Element Plus 选择控件 | 选项来自 `options`。 |
| `dict` | `Dict` | 在 `props` 中传 `code`、`codeType`、`type`。 |
| `tree-select` | `el-tree-select` | `options` 作为树数据。 |
| `date-picker` | `el-date-picker` | 日期或日期范围由 `props.type` 决定。 |
| `cron-expression` | `CronExpression` | 字符串 Cron 表达式。 |
| `transfer` | `el-transfer` | 数组值，选项键固定映射为 `value`/`label`。 |
| `image-upload`、`images-upload` | `UploadImg`、`UploadImgs` | 单图字符串，多图为地址数组或 `UploadUserFile[]`。 |
| `file-upload`、`files-upload` | `UploadFile`、`UploadFiles` | 单文件对象，多文件对象数组。 |
| `rich-text` | `WangEditor` | 富文本字符串。 |
| `dynamic-list`、`kv-list` | `DynamicList`、`KvList` | 分别为字符串数组、`{ key, value }[]`。 |
| `slot` | 页面具名插槽 | 插槽作用域为 `{ field, model }`。 |

实例方法：`validate()`、`resetFields()`、`clearValidate(props?)`。

```ts
const formRef = ref<ProFormInstance>();
const model = reactive({ name: "", status: 1 });
const fields: ProFormField[] = [
  { prop: "name", label: "名称", component: "input", props: { placeholder: "请输入名称" } },
  { prop: "status", label: "状态", component: "radio-group", options: statusOptions }
];

if (await formRef.value?.validate()) {
  // 提交 model
}
```

字段显示依赖其他字段时使用 `visible` 和动态 `props/options`；不要在业务页面复制一套 `el-form-item` 逻辑。

### `FormDialog` 和 `ProDialog`：弹窗

#### `FormDialog`

文件：`frontend/admin/src/components/Dialog/FormDialog.vue`。

必传 `v-model`、`model`、`fields`；常用属性还有 `title`、`width`、`rules`、`labelWidth`、`confirmLoading`、`destroyOnClose`、`formProps`。它内部组合 `ProDialog` 和 `ProForm`，并转发除 `footer` 外的具名插槽到 `ProForm`。

事件：

- `update:modelValue`：弹窗显示状态。
- `confirm`：点击确定，仅通知页面，不自动提交接口。
- `cancel`、`close`、`closed`：取消、开始关闭、完全关闭。

实例方法：`validate()`、`resetFields()`、`clearValidate()`。

```vue
<FormDialog
  ref="dialogRef"
  v-model="dialog.visible"
  :title="dialog.title"
  :model="formModel"
  :fields="formFields"
  :rules="rules"
  @confirm="handleSubmit"
  @close="handleClose"
>
  <template #customField="{ model }">
    <el-input v-model="model.customField" />
  </template>
</FormDialog>
```

页面应在 `handleSubmit` 中调用 `dialogRef.value?.validate()`，校验通过后请求接口，成功后关闭并刷新表格；弹窗关闭时显式重置表单和校验状态。

#### `ProDialog`

文件：`frontend/admin/src/components/Dialog/ProDialog.vue`。

适用于详情、代码配置和流程内容。属性与 `FormDialog` 的弹窗部分一致，另外有 `showFooter`；默认底部提供“确定/取消”，使用 `show-footer="false"` 或 `#footer` 覆盖。事件为 `update:modelValue`、`confirm`、`cancel`、`close`、`closed`。

### `Dict` 和 `DictLabel`：字典

文件：`frontend/admin/src/components/Dict/index.vue`、`DictLabel.vue`。

`Dict` 是全局组件，也可以显式导入。属性：

| 属性 | 说明 |
| --- | --- |
| `code` | 字典编码，必传。 |
| `codeType` | `"number"`（默认）或 `"string"`，决定回写值类型。 |
| `type` | `select`（默认）、`radio`、`checkbox`。 |
| `modelValue` | 单选值或多选数组。 |
| `placeholder`、`disabled`、`style` | 透传显示配置。 |

```vue
<Dict v-model="form.status" code="base_status" />
<Dict v-model="form.tags" code="base_tag" type="checkbox" code-type="string" />
<DictLabel v-model="row.status" code="base_status" size="small" />
```

组件通过 `useDictStore().ensureDictionary(code)` 加载或复用缓存；字典编码或值改变后会校验当前值是否仍有效。`DictLabel` 找不到值时显示空字符串，字典项 `tag_type` 仅接受 Element Plus 的 `success`、`warning`、`info`、`primary`、`danger`。

### 上传组件

上传组件默认调用 `defFileService.UploadFile(file, uploadType)`，均会感知外层 `el-form` 的禁用状态并在上传后触发表单项校验。传入 `api` 可替换上传服务，函数签名为 `(file: File) => Promise<FileInfo>`。

| 组件 | 双向绑定 | 关键属性 | 默认限制 |
| --- | --- | --- | --- |
| `UploadImg` | `v-model:image-url` | `uploadType`、`api`、`drag`、`fileSize`、`fileType`、`width`、`height`、`borderRadius`、`disabled` | 图片，5 MB，JPEG/PNG/GIF，单张。 |
| `UploadImgs` | `v-model:file-list` | 同上，另有 `limit` | 图片，5 MB，最多 5 张。 |
| `UploadFile` | `v-model:file-info` | `uploadType`、`api`、`fileSize`、`fileType`、`disabled` | 文件，20 MB，不限制 MIME（除非传入）。 |
| `UploadFiles` | `v-model:file-list` | 同上，另有 `limit` | 文件，20 MB，最多 5 个。 |

```vue
<UploadImg v-model:image-url="form.avatar" upload-type="avatar" />
<UploadImgs v-model:file-list="form.images" :limit="8" />
<UploadFile v-model:file-info="form.attachment" :file-type="['application/pdf']" />
<UploadFiles v-model:file-list="form.attachments" :file-size="50" />
```

`UploadImgs` 的 `fileList` 可以保存 `UploadUserFile[]`；通过 `ProForm` 的 `images-upload` 类型时，如果原始模型是字符串数组，组件会在回写时恢复为 URL 字符串数组。

### `TreeFilter`：树筛选

文件：`frontend/admin/src/components/TreeFilter/index.vue`。

属性：`data` 或 `requestApi` 二选一、`title`、`id`（默认 `id`）、`label`（默认 `label`）、`multiple`、`defaultValue`、`showAll`、`lazy`、`parentKey`（默认 `parent_id`）。`requestApi` 在懒加载时接收 `{ [parentKey]: parentId, lazy: true }`。

事件：`change(value)`；单选返回节点 ID，多选返回已勾选 ID 数组，点击“重置选择”返回空字符串。默认插槽作用域为 `{ row }`，用于自定义节点文本。实例暴露 `treeData`、`treeAllData`、`treeRef`。

```vue
<TreeFilter
  title="部门"
  label="name"
  :request-api="requestDeptTree"
  :default-value="deptId"
  @change="value => (tableParam.dept_id = value)"
/>
```

### `CronExpression`：Cron 编辑器

文件：`frontend/admin/src/components/CronExpression/index.vue`。

使用 `v-model` 绑定六段式 Cron 字符串，属性只有 `modelValue` 和 `placeholder`。弹窗内提供常用表达式、每段的全部/范围/步进/指定值等编辑模式，并显示表达式预览。

```vue
<CronExpression v-model="form.cron" placeholder="请输入执行计划" />
```

### `WangEditor`：富文本

文件：`frontend/admin/src/components/WangEditor/index.vue`。

使用 `v-model:value`，必传 `value`；可配置 `toolbarConfig`、`editorConfig`、`height`（默认 `500px`）、`mode`（`default`/`simple`）、`hideToolBar` 和 `disabled`。编辑器的图片、视频上传分别使用 `uploadType = image/video`，失焦时会触发表单项校验。

```vue
<WangEditor v-model:value="form.content" height="360px" mode="default" />
```

实例暴露底层编辑器引用 `editor`，仅在需要调用编辑器原生 API 时使用。

### `ECharts`：图表

文件：`frontend/admin/src/components/ECharts/index.vue`。

属性：`option`（`ECOption`，必传）、`renderer`（`canvas`/`svg`）、`resize`、`theme`、`width`、`height`、`onClick`、`onMouseup`。`ECOption` 当前包含 Bar、Line、Pie、标题、提示框、网格、数据集、图例和 DataZoom。

```vue
<ECharts :option="option" height="320" :on-click="handleChartClick" />
```

容器未设置宽高时会填充父容器，因此父级必须有确定高度。组件会监听窗口和后台布局变化，实例方法为 `getInstance()`、`resize()`、`draw()`。

### `Grid`、`GridItem` 和 `SearchForm`

`Grid` 是响应式 CSS Grid 容器，`GridItem` 是其子项；`SearchForm` 是 `ProTable` 内部使用的搜索表单，不建议业务页面直接调用。

`Grid` 属性：`cols`（数字或 `xs/sm/md/lg/xl` 断点对象）、`collapsed`、`collapsedRows`、`gap`（数字或 `[列间距, 行间距]`）。`GridItem` 属性：`span`、`offset`、`suffix` 和各断点的 `{ span, offset }`。

```vue
<Grid :cols="{ xs: 1, md: 3 }" :gap="[16, 12]">
  <GridItem :span="2">主要内容</GridItem>
  <GridItem suffix>操作区</GridItem>
</Grid>
```

`SearchForm` 由 `ProTable` 根据列的 `search` 配置生成，支持搜索折叠、重置、响应式列宽和字典搜索；只有在需要自定义表格搜索容器时才直接使用。

### 其他公共组件

| 组件 | 用途与使用方式 |
| --- | --- |
| `DataPanelCard` | 数据面板容器。必传 `title`，可传 `description`、`primary`；默认插槽为内容，`extra` 插槽为右上角操作。内容区当前固定高度 360px。 |
| `PasswordStrength` | 密码强度提示。`password` 默认空字符串，`tip` 可覆盖提示文案；强度由 `utils/passwordStrength.ts` 统一计算。 |
| `SelectFilter` | 多组横向筛选器。`data` 为 `{ title, key, multiple, options }[]`，通过 `change(value)` 返回完整筛选对象。多选组的第一项约定为“全部”。 |
| `SelectIcon` | Element Plus 图标选择器。使用 `v-model:icon-value`，可传 `title`、`placeholder`、`clearable`。 |
| `SvgIcon` | SVG symbol 图标。必传 `iconClass`，可传 `prefix`（默认 `icon`）、`size`、`iconStyle`。图标资源由 `vite-plugin-svg-icons` 从 `src/assets/icons` 注册。 |
| `ImportExcel` | Excel 导入弹窗，无 `v-model`；通过 `ref.acceptParams({ title, tempApi, importApi, getTableList, fileSize, fileType })` 打开。最多上传一个文件，默认 5 MB。 |
| `Loading` | 页面级加载占位，无属性和事件，通常由 `indexAsync.vue` 的 `Suspense` fallback 使用。 |
| `SwitchDark` | 暗黑模式开关，无属性；直接读写全局 store，主题设置抽屉已内置使用。 |

`ErrorMessage/403.vue`、`404.vue`、`500.vue` 是路由错误页，不作为业务表单或列表组件使用。

## 管理后台内部组件

### 布局组件

入口为 `frontend/admin/src/layouts/index.vue`（同步）或 `indexAsync.vue`（异步）。当前支持四种布局：

| 布局 | 文件 | 结构特点 |
| --- | --- | --- |
| `vertical` | `LayoutVertical/index.vue` | 左侧菜单、顶部工具栏、主内容。 |
| `classic` | `LayoutClassic/index.vue` | 顶部品牌区与左侧菜单组合。 |
| `transverse` | `LayoutTransverse/index.vue` | 顶部横向菜单。 |
| `columns` | `LayoutColumns/index.vue` | 分栏菜单与内容区。 |

布局内部组件包括：

- `Main`：承载 `router-view`、页面最大化和 KeepAlive。
- `Tabs`、`MoreButton`：多标签导航和标签操作。
- `ThemeDrawer`：布局、主题颜色、暗黑/灰色/色弱、菜单和页脚设置。
- `ToolBarLeft`、`ToolBarRight`：头部工具栏组合；内部包括 `CollapseIcon`、`Breadcrumb`、`SearchMenu`、`Ai`、`AssemblySize`、`Fullscreen`、`Avatar`、`ThemeSetting`、`InfoDialog`、`PasswordDialog`。
- `SubMenu`：递归渲染动态菜单，接收 `menuList: RouteItem[]`；菜单组件路径和权限由路由/菜单数据决定。
- `Footer`：读取配置 store 渲染页脚。

这些组件依赖 Pinia、路由和全局事件总线，业务页面不应直接复用或改造其内部状态；修改布局时从 `globalStore`、`authStore` 和 `configStore` 的现有状态入口接入。

### 页面私有组件

页面私有组件放在最接近的业务目录，不应为了单个页面使用而提升到 `src/components`：

| 目录 | 组件 | 说明 |
| --- | --- | --- |
| `views/base/login/components` | `LoginForm` | 登录、验证码、OAuth 登录表单，只服务登录页。 |
| `views/base/ai/chat/components` | `ChatPanel`、`SessionPanel`、`XSender`、`AiMarkdown` | AI 会话消息、会话列表、输入发送器和 Markdown 渲染；由 AI 页面统一编排。 |
| `views/system/base/user/components` | `dept-tree` | 用户管理的部门树筛选。 |
| `views/system/profile/components` | `base`、`password`、`security` | 个人中心的资料、密码、安全设置子面板。 |
| `views/system/tool/code-gen/components` | `CodePreviewPane`、`CodeGenProgressDialog` | 代码生成预览和 SSE 进度弹窗。 |

AI 和代码生成组件的属性、事件都是页面内部协议，修改时应同时检查父页面的状态编排和接口调用，不要将其当作稳定公共组件使用。

## 应用端组件

应用端当前使用 uni-app，公共组件目录 `frontend/app/src/components` 尚未建立；AI 页面组件位于 `frontend/app/src/pagesMember/ai/components`，只服务 `/pagesMember/ai/index.vue`：

| 组件 | 属性 | 事件 | 用途 |
| --- | --- | --- | --- |
| `Composer` | `modelValue`、`attachments`、`placeholder`、`bottom`、`recording`、`sending`、`disabled` | `update:modelValue`、`attach`、`record`、`send`、`remove-attachment` | 文本输入、附件预览、语音和发送按钮。 |
| `SessionDrawer` | `open`、`topPadding`、`keyword`、`loading`、`sessions`、`activeSessionId` | `close`、`create`、`select`、`action`、`update:keyword` | 历史会话抽屉、搜索、选择和长按操作。 |
| `WelcomePanel` | `greetingMessage`、`loading`、`shortcuts`、`canRefresh` | `refresh`、`shortcut-tap` | 空会话欢迎语和快捷提问。 |

应用端组件遵循 `script setup + TypeScript`，事件由页面负责请求、登录态检查和流式消息编排。不要在这些组件内直接调用 service 或修改全局 store；只有在至少两个页面复用且不含业务语义时，才考虑提升到 `frontend/app/src/components`。

## 组件使用规范

1. 列表页默认采用 `ProTable + FormDialog + ProForm`；页面负责请求编排、弹窗状态、表单回填、提交、删除和刷新。
2. 能用 `columns`、`headerActions`、`cellType`、`actions` 表达的表格内容，不重复写 `el-table-column` 插槽。
3. 业务类型优先从 `src/rpc` 生成文件导入；组件接口类型从对应组件的 `interface/index.ts` 导入，不重复声明同名结构。
4. `Dict`、上传、富文本都可能异步加载数据或触发表单校验，提交前先等待 `validate()`；不要只依赖按钮禁用状态。
5. 上传组件的 `api` 必须返回 `FileInfo`，业务分类通过 `uploadType` 传递，避免所有文件落入默认分类。
6. 自定义颜色和布局样式优先复用全局主题变量，兼容亮色、暗黑、灰色和色弱模式；公共组件不要写死业务页面颜色。
7. 组件内部方法或属性不是稳定 API 时，以源码中 `defineExpose`、`defineEmits` 和接口文件为准；不要依赖未暴露的内部 ref。
8. 新增通用组件前先确认至少有两处真实复用，页面特有流程留在页面目录；新增或修改组件后按模块执行 lint/type-check。
