## 管理端协议接入

site=2 的四个配置项为 `1191 adminServiceProtocol`、`1192 adminServiceProtocolVersion`、`1193 adminPrivacyProtocol`、`1194 adminPrivacyProtocolVersion`，正文为富文本、版本为文本。初始化正文是基础项目示例，不能替代宿主的正式协议。正文变更时同步提升版本并刷新配置缓存。

管理端密码入口为 `POST /api/v1/admin/base/session`（`/base.v1.LoginService/AdminLogin`）；管理端 OAuth 授权入口为 `POST /api/v1/admin/base/oauth/authorization`（`/base.v1.OauthService/CreateAdminOauthAuthorization`）。两个 operation 均需匿名认证白名单，当前最小/完整配置已同步，API 注册由 Proto 在启动时同步。

页面使用 `/login?protocol=service`、`/login?protocol=privacy` 匿名阅读，仅读取管理端配置，不回退到移动端 `serviceProtocol/privacyProtocol`。初次加载、配置/版本改变后复选框均为未选；密码和第三方登录均检查主动确认。OAuth 使用服务端 state 保存确认上下文，MFA 使用同一挑战载荷保存管理端标识和确认；完成认证前复验当前版本/摘要，成功后写现有操作日志 `resource_type=admin_agreement`，包含用户/租户、IP、请求标识、版本、正文摘要和服务端确认时间，不新增表。

管理端协议门禁针对专属认证流程。共享应用端登录仍可签发同一账号体系的令牌，未引入终端 token audience 或管理端 API 的全局协议门禁；若要求任意客户端访问管理 API 都先同意协议，需要整体升级会话/授权契约，不能通过账号角色猜测终端。

## 存量环境升级顺序

1. 备份数据库、配置密文和密钥，核验能恢复；不得为重放 `v0.0.1` 重建生产库。初始化脚本仅维护完整新安装状态，已执行的数据库不会自动重放。
2. 补齐四个管理端配置，完善正式协议与版本。宿主认证白名单同步新增两个 operation；旧授权/配置缓存按项目管理入口刷新。
3. 盘点 Lua/TCL 等停用语言脚本，迁移为允许语言再启用；新版本会拒绝执行，包括已保存的旧脚本。确认工作流仍只用 JavaScript 快照。
4. 盘点保留用户名和产品别名，确认新账号名无冲突后通过管理接口改名，保留用户 ID、角色和关联，撤销该用户所有会话。存量未改名保留账号仍能登录和维护其他资料，避免升级锁死；须在整改窗口完成改名。
5. 核对存储/出库策略、历史明文和旧格式；按表备份并分批重存，验证解密、摘要查询和掩码。不要修改掩码值后覆盖原文，也不要仅替换主密钥。配置回填不覆盖全部业务字段。
6. 将实际日志配置、归档规则和采集平台更新为至少六个月；建议 365 天。确认 `max_backups=0` 不再按文件数量提前删除，按业务量预留磁盘和告警。回退目录必须为持久存储并验证 HMAC 重放；HMAC 是篡改检测，不能代替独立备份和访问控制。
7. 由于报告已证明代码执行和配置读取，部署方须轮换可能暴露的数据库、Redis、JWT、OAuth、消息、AI 及集群凭据并撤销旧会话。数据加密主密钥轮换需保留旧密钥并完成重加密/恢复验证，不能直接替换导致历史数据不可读。
8. 发布后在授权测试环境复测 11 项，保存响应、数据库脱敏样本和审计关联证据，最后由测试组复核。

`cloud-scp` 第 2、3 项源码已经补齐，但宿主当前仍依赖已发布的基础包；本仓库其他整改不会自动进入宿主制品。先发布基础后端与前端包，再按宿主升级规则统一依赖版本，最后构建和复测完整应用。

## 安装与中间件加固

- 网关启用 HTTPS 和证书校验，限制管理入口来源，设置符合上传需求的请求体/超时/连接数；关闭版本响应头和目录索引。SSE 保持必要的长连接配置，不缓存跨用户响应。
- MySQL/PostgreSQL、Redis、消息队列、对象存储和管理控制台仅向必要业务网段开放。使用独立应用账号和最小权限，禁用匿名/默认凭据，运维入口不暴露公网；按环境启用 TLS、ACL 和备份恢复。
- 容器使用非 root、最小能力、只读配置和独立持久卷，不挂宿主根目录、Docker socket 或运维密钥。业务脚本无宿主能力不等于进程资源完全隔离；执行资源和容器配额仍须限制。
- 根密钥通过受控文件/Vault/KMS/Secret 提供，密钥与数据库备份分开授权。日志、错误、镜像层及前端构建产物不得包含凭据，调试/pprof/运行控制台仅授权运维可访问。
- 集群连接确需访问内网，不能一律禁止内网。由平台管理员维护准确的主机、端口和必要 CIDR 白名单，业务表单不能自行扩宽策略；覆盖最终 kubeconfig server、代理、DNS 所有地址、IPv6、重定向和最终拨号，阻断元数据、回环、链路本地等非业务目标。
