# 日志与审计

本文描述当前仓库的运行日志、任务日志和六类业务审计日志。日志查询只读，事件写入由后端业务流程异步完成。

## 日志分类

| 类型 | 表 | 记录内容 | 管理端入口 |
| --- | --- | --- | --- |
| 登录日志 | `base_login_log` | 登录成功、失败、验证码、MFA、来源和会话结果 | 系统管理 / 日志审计 / 登录日志 |
| 接口访问日志 | `base_api_log` | HTTP/gRPC 请求、状态、耗时、请求身份和响应摘要 | 接口访问日志 |
| 操作日志 | `base_operation_log` | 新增、修改、删除、导入、导出和批量操作 | 操作日志 |
| 数据访问日志 | `base_data_access_log` | 数据资源、范围、返回条数和敏感字段触达 | 数据访问日志 |
| 权限日志 | `base_permission_log` | 权限检查、允许/拒绝、资源和操作 | 权限日志 |
| 策略评估日志 | `base_policy_evaluation_log` | 策略引擎、评估类型、决策和耗时 | 策略评估日志 |

`base_job_log` 单独记录定时任务执行结果，不属于安全审计六类。`BaseLogService.GetBaseLogTrace` 可以按 `request_id` 或 `trace_id` 汇总同一请求的相关记录。

## 统一字段与脱敏

每条日志保存发生时的租户、用户、角色、请求、来源地址、设备、结果、耗时和创建时间快照。历史展示不依赖后续用户或组织数据恢复名称。

请求头、请求体、响应体、Cookie、Token、密码、API Key、OAuth/消息 Provider 凭据和配置敏感值默认脱敏。数据访问日志只记录真实响应中可识别的字段范围、条数和敏感字段触达标志，不猜测 SQL、表名或 SQL 指纹。

日志详情只返回脱敏后的内容；原始日志文件下载需要独立权限，并受文件访问策略保护。

## 异步写入

请求线程只向有界缓冲投递事件，后台消费者完成序列化、脱敏和批量写库。队列可用时使用 Redis 队列；单实例未配置 Redis 时使用进程内队列。缓冲区满、队列不可用或事件序列化失败时不阻塞请求，也不在请求线程同步写库。

每个事件包含稳定的幂等编号。写库成功但确认失败后重复投递时，消费者按幂等编号识别已处理事件。登录、操作、数据访问和权限事件由各自业务中间件产生；接口访问和策略评估事件由 HTTP/gRPC 请求链路产生。

## 回退与保留

当异步写入暂时不可用时，系统可根据隐藏配置 `baseLogFallback` 将事件写入 `admin-log.jsonl`。文件内容使用运行时密钥生成 HMAC，`system.admin.BaseLogFallback` 任务每日补写日志表并记录失败原因。回退文件应放在独立磁盘并配置告警。

`system.admin.BaseTableArchive` 按 `base_table_archive` 的启用配置归档超过在线保留期的数据；只有归档校验成功并允许删除时才清理在线记录。应用运行日志由日志配置负责轮转和压缩。

## 服务与权限

六类日志服务均提供分页和详情接口，不提供面向普通客户端的创建接口：

```text
PageBaseLoginLog / GetBaseLoginLog
PageBaseApiLog / GetBaseApiLog
PageBaseOperationLog / GetBaseOperationLog
PageBaseDataAccessLog / GetBaseDataAccessLog
PageBasePermissionLog / GetBasePermissionLog
PageBasePolicyEvaluationLog / GetBasePolicyEvaluationLog
```

所有查询按当前租户和操作者权限过滤。平台管理员可查看全部租户；租户管理员只能查看本租户；普通用户只能在个人中心查看自己的登录记录。详情按钮和菜单权限维护在 `backend/migration/assets/v0.0.1/mysql`。

## 运维检查

```bash
make menu-sort
make check
```

生产环境至少检查：异步缓冲是否持续堆积、队列 pending 数、最老事件年龄、回退文件增长、归档任务结果、日志查询权限和敏感字段脱敏结果。日志故障不能阻断登录、鉴权和普通业务请求。
