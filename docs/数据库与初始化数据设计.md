# 数据库与初始化数据

## 当前数据源

系统默认使用 MySQL 数据库 `kratos_admin`，配置位于 `backend/configs/data.yaml` 和 `data_local.yaml`。Redis 用于验证码、一次性密码密钥、Token 等缓存状态。

`data.database` 表示单一默认数据源；`data.databases` 可声明多个命名数据源。默认数据源保存系统表以及所有模块的 `base_migration` 执行记录。

## 建表和迁移

启动顺序为：

1. 创建全部 GORM 客户端。
2. 对 `enable_migrate: true` 的客户端执行注册模型的 `AutoMigrate`。
3. 加载模块迁移资源，按依赖、版本、数据库类型和数据源执行 `.up.sql`。
4. 完成 OpenAPI 接口数据、租户角色菜单和 Casbin 策略同步。

`enable_migrate` 只控制 GORM 自动建表，不会关闭版本化 SQL。全新环境应为默认数据源启用它，否则 `base_migration` 等表可能尚不存在。

## 资源结构

当前内置资源：

```text
backend/migration/assets/v0.0.1/mysql/
├── base_area.up.sql
├── default_data.up.sql
├── default_data.description.md
├── i18n.en-US.up.sql
├── i18n.zh-TW.up.sql
└── i18n.ja-JP.up.sql
```

目录规则：

```text
assets/<version>/<database-type>/<feature>.up.sql
assets/<version>/<database-type>/<feature>.down.sql          # 可选
assets/<version>/<database-type>/<feature>.description.md
assets/<version>/<database-type>/<data-source>/<feature>.up.sql
```

当前仓库内置并验证的是 `mysql`。数据库类型目录下的直系文件属于 `default` 数据源；一级子目录是命名数据源，必须与配置名称一致。需要接入其他数据库类型时，必须先确认对应驱动、模型迁移和 SQL 方言，再新增迁移目录。脚本和描述按文件名排序读取。

迁移记录唯一标识包含模块、数据源和版本。一个版本内任一升级脚本失败会回滚该版本并阻止服务启动，修复后重启会重试未记录版本。

## 初始化内容

`default_data.up.sql` 提供：

- 默认租户、部门、岗位、角色和 `super`、`admin` 开发账号。
- 系统配置、字典、菜单、按钮和服务方法权限关系。
- 管理端 System 页面、AI、代码生成、API 文档和应用端所需权限入口。

`default_data.up.sql` 负责语言记录、默认业务数据、菜单和权限；同版本 `i18n.{locale}.up.sql` 通过 `base_i18n.target_type` 提供菜单、字典、字典项和系统配置名称/值的非主语言译文。五类翻译数据按单条 `INSERT IGNORE` 写入。主语言由 `base_language.is_primary` 配置，主表保存主语言文本，其他启用语言保存到统一翻译表。翻译表及代码生成 `i18n_config` 字段由 GORM `AutoMigrate` 创建。

`base_area.up.sql` 提供地区基础数据。初始化 SQL 使用 `INSERT IGNORE`，遇到已有唯一键记录时跳过，不覆盖已有数据。

启动时 `BaseApiCase.InitializeOpenAPI` 根据已注册 OpenAPI 重建接口元数据，随后同步租户管理员菜单并重建 Casbin 规则。因此修改 Proto 路径或菜单 API 列表时，必须同时重新生成 OpenAPI 并更新版本化 SQL。

## 新环境

```sql
CREATE DATABASE kratos_admin CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

启动后端后，默认开发账号为：

- `super / 112233`
- `admin / 112233`

这些凭据只用于本地初始化，部署前必须修改。

## 存量升级

- 不修改已经发布并执行的版本目录，新增更高版本。
- 结构变更、数据修复、菜单和权限调整放在同一功能版本中。
- 新增语言先按[国际化语言扩展指南](国际化语言扩展指南.md)生成语言包和 `language.up.sql`；动态固定译文另生成 `i18n.<locale>.up.sql`。
- SQL 保持幂等，避免 `TRUNCATE`、无条件全表更新或删除。
- 生产执行前备份并验证回滚策略；需要回退时显式提供 `.down.sql`。
