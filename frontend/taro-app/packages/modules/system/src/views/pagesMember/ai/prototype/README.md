# Taro AI 助手侧栏原型

基于当前 Taro AI 页面的交互原型，在历史会话抽屉顶部增加“定时任务、文件、插件”入口，保留现有导航栏、对话气泡、输入框、底部导航、搜索框和会话卡片。输入框紧贴底部导航上方。

预览服务直接编译当前仓库的主题和组件 SCSS，并使用 Taro 自带 `postcss-pxtransform` 完成 750px 设计稿到 H5 rem 的转换。示例数据仅存在内存，不接后端，不修改正式组件。

```bash
node frontend/taro-app/packages/modules/system/src/views/pagesMember/ai/prototype/serve.mjs
```

打开 <http://127.0.0.1:4174/?drawer=1>。保留当前 Taro H5 导航栏右侧的历史按钮，通过该按钮展开左侧抽屉。画布外的评审按钮用于切换明亮/暗黑，属于原型控件。

- `?drawer=1`：默认展开侧栏。
- `?view=automations`、`?view=files`、`?view=plugins`：预览管理页。
- `?theme=dark`：预览 Taro 暗色主题。

使用 workspace 已安装的 Sass、PostCSS 和 Taro 编译依赖；无需安装其他依赖。修改源样式后重启预览服务。

## 移动端只读范围

| 功能 | 可查看的内容 |
| --- | --- |
| 定时任务 | 搜索、状态筛选、计划配置、下次执行时间、执行记录、冻结配置详情、只读结果及待确认信息 |
| 文件 | 全部/上传/生成/回收站分类和数量、搜索、活动文件预览与下载、回收站文件信息 |
| 插件 | 目录及可见范围筛选、插件详情、启用状态和开放终端、连接账号状态与授权范围、工具参数及现有调用策略 |

三个管理区均不提供新增、编辑、删除、上传、恢复、连接、启停、执行、审批等写操作入口，对应处理逻辑一并移除。

日常对话保留新建会话、搜索切换历史、正常发送和停止生成、复制与回复信息、模型/知识库选择、附件及语音识别结果模拟；历史会话和已有消息不再提供重命名、编辑、删除或分支入口。

对话始终根据语意自动匹配已启用、开放应用端且可用的工具，不提供会话插件选择器。定时任务结果只读打开，确认信息仅展示，需在管理端处理。

## 管理端参考

功能取自 `frontend/admin/packages/modules/system/src/views/ai/chat/workspace/` 下的 `AutomationPanel.vue`、`FilePanel.vue`、`PluginPanel.vue`，以及 `components/AiSessionPanel/index.vue`、`views/ai/chat/components/ChatPanel.vue` 和 `XSender.vue`。

移动端按本次要求只展示这些功能的只读信息，管理操作在管理端完成。

## 演示边界

- 数据只存在内存，刷新页面或点击画布外“重置”恢复初始示例。
- 定时任务和连接状态为只读示例；下次执行时间支持 IANA 时区计算。
- MCP 地址不会发起网络连接，不提供凭据输入或授权操作。
- 对话附件仍可从已有文件或本地文件中选择，每个本地附件最大 20 MB；文件管理页不提供上传入口。下载使用本地 Blob。
- 语音入口用文本模拟识别结果，不访问麦克风。
