# AI 对话原型

这是用于验证移动端 AI 对话信息架构的临时原型，不连接接口，也不改变生产页面。

## 运行

```bash
python3 -m http.server 4173 --directory frontend/uni-app/packages/modules/system/src/views/pagesMember/ai/prototype
```

打开 <http://127.0.0.1:4173/>，默认是 390×844 的移动端画布。底部切换条可以比较三种移动端方案，也可以直接打开 `?variant=A`、`?variant=B` 或 `?variant=C`；追加 `&desktop=1` 才显示宽屏调试布局。

## 设计问题

用户只描述目标，插件和工具由系统根据语意自动匹配；模型与知识库仍保留为可选上下文。原型通过发送“总结”“数据”“计划”等示例，展示自动匹配状态如何出现在回复上下文中。

- A「对话优先」：默认推荐，适合日常工作问答。
- B「任务工作台」：强调连续任务和结果拆解。
- C「极简输入」：最大化输入区，适合高频使用。
